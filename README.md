# Accra 3am

A single-page editorial site set at 3:17 AM at Kwame Nkrumah Circle, Accra: the last trotro gone, neon on wet tar.

`index.html` is the whole site, with its CSS, JavaScript and hero photo embedded. Fonts load from Google Fonts. There is no build step, so it deploys to any static host as it is.

## Project docs

- `CLAUDE.md`: project brief and technical stack
- `PRD.md`: requirements and success criteria
- `DESIGN_STANDARD.md`: visual specification
- `SITE_CONTRACT.md`: page structure and behaviour
- `CONTENT_MODEL.md`: all page copy and field constraints

The built site differs from the docs in a few places, including stronger rain, a higher `--text-dim` opacity and dim instead of ghost for readable labels. The site is the current reference for those values.

## Before launch

- Replace the placeholder contact address `hello@example.com` in `index.html`.
- Confirm the rights to the hero photo of Kwame Nkrumah Circle and add a credit if one is required.
